새 인증서 발급

1. 발급 방식 · 프로파일

CA가 서명 자체 서명 (Self-signed)
CA를 선택하세요.
발급자 (Issuer)
Subject와 같음 — 이 인증서의 키로 스스로 서명합니다. 주로 Root CA를 만들 때 씁니다.
CA 등록 오류
CA 프로파일일 때만. 등록하면 발급 CA 목록에 나타나 하위 인증서를 발급할 수 있어요.
프로파일 오류
CA와 맞지 않는 조합은 제출 시 서버가 거부합니다.
유효기간 오류
프로파일 상한을 넘으면 서버에서 거부합니다.
시작 시각 오류
비워두면 발급 시각. 과거 시점은 허용하지 않습니다.

2. 키 소스

CSR 업로드 CSR 업로드 KMS 키 사용 서버 생성 (PKCS#12)
자체 서명은 서버가 개인키로 직접 서명해야 해서 CSR 업로드는 쓸 수 없어요. KMS 키 또는 서버 생성을 고르세요.
키 소스 오류
KMS 키 오류
등록된 키가 없습니다. 키 관리에서 먼저 키를 만드세요.
내장 KMS의 키로 CSR을 자체 서명해 POP를 확보하며, 개인키는 KMS 밖으로 나오지 않습니다.
알고리즘 오류
비밀번호 오류
발급 직후 PKCS#12 파일을 한 번만 내려받을 수 있습니다(5분 유효). 서버는 생성한 개인키를 보관하지 않습니다.
CSR 파일 오류
CSR 오류
CSR 서명(Proof of Possession)을 검증합니다. 아래 Subject를 비워두면 CSR 값을 사용하고, 입력하면 덮어씁니다.
